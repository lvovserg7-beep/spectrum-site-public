Что изменили в посеве (по продуктам)

1. Модуль МП — /casemarketplace Опубликовано

Title: «Модуль 1С для маркетплейсов Ozon и Wildberries | Аллсан». Description с ценой от 40 700 ₽/год. Коммерческий абзац под H1. Снят сквозной виджет Telegram (T825/BF905) с Header. Переобход в Вебмастере.

Влияние на позиции/клики

Плюс: ключ «модуль» в title → рост позиций и CTR; цена в тексте → Яндекс тянет сниппет со страницы; снятие TG → меньше интент-шума. Минус/риск: meta description Яндекс часто игнорирует; CTR всё ещё ниже бенчмарка 2–5% на поз. 4–10.

2. B2B поставщики — /ecom, /etm-ipro, кейс Опубликовано

Title/description /ecom и /etm-ipro. Organization + WebSite (сайт) + Service на /ecom. Кейс → /caseecomsc с новым title/desc, H1 и schema.

Влияние

Плюс: коммерческий сниппет и schema для GEO. Минус: основной спрос Wordstat — «мерлион/ocs b2b» (вход в ЛК), не «интеграция с поставщиком»; CTR почти не сдвинулся. Риск смены URL кейса без 301 на старте (позже выровняли).

3. Внедрение 1С — /development1c, /kompleksnaya_avtomatizaciya Опубликовано

Живой HTML 07.09: title/H1 «Внедрение 1С под ключ — УТ, КА, ERP»; на КА — title/H1 про внедрение КА; Service schema есть.

Влияние

Плюс: снят смешанный сниппет «купить + поддержка». Минус/риск: смена title на уже ранжируемой КА-странице могла дать краткий качок позиции (в брифе риск 1–3 недели); в окне «после» кликов по контрольным ключам ещё 0.

4–6. Поддержка · Лицензии · Главная · Доработка Не посеяно / план

/support1c — только EPR, meta на живом сайте не меняли. Лицензии — бриф начат ~31.08, публикация не подтверждена. Главная — разбор структуры без смены title. Доработка — в топе Вебмастера нет запросов. На метрики посева эти продукты почти не влияют.

Сквозные действия Кабинеты

GSC: оставлены рабочие sitemap, feeds/apps сняты. Удалены битые внешние ссылки на /publication. robots.txt на Тильде не правился (ограничение платформы).

Плюс / минус: что могло сдвинуть позиции и клики

Скорее положительно
  • Title МП с ключом «модуль» + Ozon/WB
  • Цена и коммерческий абзац (сниппет Яндекса)
  • Рост позиций МП 7–9 → 4–5 → больше кликов
  • Снятие TG-виджета (продукт снят с продажи)
  • Title/H1 внедрения без смеси с поддержкой
  • Schema Organization / Service
  • Переобход Вебмастера + чистка sitemap в GSC
Скорее отрицательно / риск
  • Meta description почти не в сниппете Яндекса
  • CTR МП 0,65% всё ещё ниже нормы 2–5%
  • Смена title КА — краткая турбулентность
  • B2B: трафик навигации в ЛК, не коммерция
  • Google: /casemarketplace поз. ~29 при росте показов
  • Старые TG/Bitrix-страницы оттягивают Google
  • Поддержка/лицензии без посева = нет эффекта
