## Что считать готовым

- правка видна на живом сайте;
- или задача заменена более новой инструкцией (та же задача или страница в более новом файле) - тогда строка «перенесено в {файл}»;
- или задача явно помечена SKIP / «не делаем».

Если по HTML проверить нельзя (кабинет Вебмастера, GSC, Яндекс Бизнес, Карты, настройки без следа в HTML), задачу оставить открытой и вписать в отчёт как «не проверить».

## Как проверять

- Качать HTML страницы с параметром против кэша, например `https://alsn.ru/development1c?chk=2909`.
- Python запускать только из .py-файла (не `python -c`). Скрипты класть в `c:\Users\ALSN_LSA\Desktop\Спектр\cursor\Сайт\seo-data\scripts\` с префиксом из своего задания. Shell вызывать с `required_permissions: ["all"]`, перед запуском `$env:PYTHONIOENCODING='utf-8'`.
- Сверять: title, meta description, og:*, H1/H2, «Заменить на» (новая строка есть, старой «Найти» нет), JSON-LD и код в HEAD, alt, meta robots, цены, наличие блоков.

- Готовую задачу убрать целиком: заголовок, «Что сделать», «Зачем», клики, блоки копирования, её пункт в оглавлении и в «Порядке».
