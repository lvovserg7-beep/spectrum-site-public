# Фирменная система изображений Аллсан

Актуальная концепция: **«Контур управления»** (11.09.2026).

## Идея

Аллсан связывает данные, учёт и действия бизнеса в один управляемый маршрут:

**входные данные → модуль / команда Аллсан → измеримый результат**.

Визуальный язык отражает деятельность компании: схемы обмена, прямоугольные
карточки процессов, тонкие связи и оранжевый сигнал движения.

## Канон

- фон `#F7F8FA`;
- графит `#212121`;
- оранжевый сигнал / CTA `#F55823`;
- линии `#D7DADD`;
- один экран — одна задача — один результат;
- крупная типографика, много воздуха;
- логотип только из `seo-data/logo/`, не генерация;
- люди, интерфейсы и документы — только реальные.

Эталон: `allsun-brand-board-2026.png`.

## Что взято из исследования

- 1С-Рарус: структурирование продуктов и воздух;
- ГЭНДАЛЬФ: вход через бизнес-задачи и статусы;
- WiseAdvice IT: кейсы с измеримым результатом;
- КОРУС Консалтинг: уверенная типографика и ощущение масштаба;
- 1С-АБ: FAQ и конкретные пакеты;
- Айтекс: механика витрины лицензий;
- Кодерлайн: цифры и проекты.

Не копируем синюю палитру конкурентов, 3D-декор, карусель, каталожный шум,
магазинные бейджи и стоковые офисные фотографии.

## Где применять

- сайт: полный логотип в шапке; внутри секций — маршруты и карточки;
- презентации: логотип можно делать крупнее;
- OG / Telegram: 1200×630, текст в центральном квадрате 630×630
  (`allsun-og-ecom-suppliers.png`, `allsun-og-licenses.png`);
  слайд 16:9 в превью ссылки не ставить;
- кейсы: схема + реальный скриншот / отзыв / фото;
- тёмный графит: только для отдельной карточки результата или локального
  контраста, не как основной фон.

Публикация на живой Тильде или в Битрикс — отдельная задача.
