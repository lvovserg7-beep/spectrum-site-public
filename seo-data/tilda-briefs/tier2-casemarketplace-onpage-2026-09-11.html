Зачем

Чтобы не править чужую страницу. Вся эта инструкция — только про модуль маркетплейсов.

Как в Тильде

  3. В списке страниц найти адрес casemarketplace.
  4. Навести на строку → иконка карандаш = редактор холста. Иконка шестерёнка = настройки страницы.

T2-1 Картинка при пересылке ссылки + название компании

Что сделать

Загрузить картинку 1200×630 пикселей — ту, что видят люди, когда ссылку кидают в Telegram, WhatsApp, VK и т.п. Указать название компании: Аллсан Интеграция.

Зачем

Сейчас при пересылке ссылки превью мелкое и «мыльное». Нормальная большая картинка и название компании выглядят солиднее — человек чаще открывает ссылку, а не пролистывает дальше.

Подготовка файла (до Тильды)
  1. Сделать JPG или PNG ровно 1200×630.
  2. Содержание: модуль / Ozon+WB / бренд Аллсан. Без мелкого текста.
  3. Вес желательно < 300 КБ.
  4. Сохранить на диск, например casemarketplace-og-1200x630.jpg.
Как в Тильде — картинка
  1. Список страниц → casemarketplace → шестерёнка.
  2. Вкладка Facebook & SEO (иногда «Соцсети» / «Open Graph»).
  3. Блок картинки превью / «Изображение для Facebook» / «Картинка для соцсетей».
  4. Кнопка Загрузить / «Выбрать файл» → выбрать файл 1200×630.
  5. Если Тильда предлагает кроп — оставить 1200×630, без обрезки в квадрат.
  6. Кнопка Сохранить внизу окна настроек.
Как в Тильде — название компании
  1. Там же, вкладка Facebook & SEO: поле «Название сайта» / Site name → вставить:
Аллсан Интеграция
  1. Если такого поля нет → вкладка Дополнительно → «HTML-код для вставки внутрь HEAD».
  2. Прокрутить в конец поля. Уже стоящий код не удалять — только дописать снизу.
  3. С новой строки вставить:
<meta property="og:site_name" content="Аллсан Интеграция">
  1. Сохранить.
  2. В списке страниц у casemarketplace → Опубликовать (или в редакторе сверху справа «Опубликовать»).

T2-2 Строка навигации «Главная → …» на странице

Что сделать

Над большим заголовком страницы показать строку: Главная → Модуль 1С для маркетплейсов. В Тильде готового блока для этого нет — ставим блок HTML (T123) и вставляем готовый код.

Зачем

Посетитель сразу понимает, где он: пришёл с главной на страницу модуля. Яндекс и Google тоже смотрят эту строку — без неё на экране нельзя честно «рассказать» им про путь по сайту (это следующая задача T2-3).

Как в Тильде
  1. Список страниц → casemarketplace → карандаш.
  2. Найти блок с большим заголовком «Модуль интеграции 1С…» (это главный заголовок страницы).
  3. Навести на этот блок → «+» → «Добавить блок сверху».
  4. В библиотеке: категория «Другое» / поиск HTML → блок T123 «HTML-код». Не искать «хлебные» / breadcrumb.
  5. Клик по новому блоку T123 → поле кода → вставить целиком:
<nav aria-label="Хлебные крошки" style="font-size:14px;line-height:1.4;color:#666;padding:8px 20px 0;">
  <a href="https://alsn.ru/" style="color:#666;text-decoration:none;">Главная</a>
  <span style="margin:0 6px;">→</span>
  <span style="color:#333;">Модуль 1С для маркетплейсов</span>
</nav>
  1. В настройках блока T123: отступы сверху/снизу минимальные (или 0), чтобы строка не отодвигала заголовок далеко вниз.
  2. Вверху редактора → Сохранить → Опубликовать.
Слова «Главная» и «Модуль 1С для маркетплейсов» должны совпадать с кодом в T2-3 буква в букву. Код из T2-3 в этот блок HTML не вставлять — туда только видимая строка для людей.

T2-3 Та же навигация — служебный код для Яндекса и Google

Что сделать

Вставить готовый кусок кода в настройки этой страницы (вкладка «Дополнительно», поле для кода в HEAD). На экран человеку он не рисуется — его читают поисковики. Общие настройки всего сайта не трогать.

Зачем

Чтобы в результатах поиска рядом со ссылкой могла появиться цепочка вроде «Аллсан → Модуль…». Так проще понять, что за страница, и чаще кликают. Код без видимой строки с T2-2 поисковики обычно не принимают — поэтому сначала T2-2, потом этот шаг.

Как в Тильде
  1. Сделать сначала T2-2 (видимые крошки).
  2. casemarketplace → шестерёнка → вкладка Дополнительно.
  3. Поле «HTML-код для вставки внутрь HEAD».
  4. Прокрутить в конец. Уже стоящий код не стирать — только дописать снизу.
  5. С новой строки вставить весь блок ниже.
  6. Сохранить → Опубликовать страницу.
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://alsn.ru/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Модуль 1С для маркетплейсов",
      "item": "https://alsn.ru/casemarketplace"
    }
  ]
}
</script>
Настройки страницы → Дополнительно → HTML в HEAD → в конец → Сохранить → Опубликовать

T2-4 Подписи к картинкам

Что сделать

У каждой смысловой картинки заполнить поле Alt (альтернативный текст) по таблице ниже. Мелкие декоративные иконки не трогать — у них alt пустой.

Зачем

Если картинка не загрузилась или человек пользуется программой чтения с экрана — виден текст вместо картинки. Плюс Яндекс и Google по этим подписям могут показывать ваши картинки в поиске по изображениям. Сейчас у большинства картинок модуля подпись пустая — поисковик и вспомогательные программы «не понимают», что нарисовано.

Как в Тильде (общий приём)
  1. Редактор casemarketplace (карандаш).
  2. Клик по картинке в блоке → панель справа/всплывашка.
  3. Поле Alt / «Альтернативный текст» / «Описание изображения».
  4. Вставить текст из таблицы → Enter / закрыть панель.
  5. После всех картинок: Сохранить → Опубликовать.
