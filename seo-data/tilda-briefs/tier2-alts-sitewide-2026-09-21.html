Как ставить Alt

Что сделать

Вписать короткую подпись в поле картинки. На красивой странице её обычно не видно.

Зачем

Если фото не загрузилось или человек читает сайт программой - понятно, что на картинке. Поиск тоже смотрит эту подпись.

Обычный блок на странице
  1. Карандаш страницы → блок с картинкой → Контент.
  2. Напротив фото - многоточие «…» → «SEO: alt-текст для изображения».
  3. В галерее - ссылка «Текст» → Image alt for SEO.
  4. В Zero Block - элемент картинки → поле ALT.
  5. Сохранить → Опубликовать.
Контент → … / Текст / ALT → вставить → Сохранить → Опубликовать

Подробнее: tilda-how-to-alt-2026-09-11.html в этой папке.

Товар каталога
  1. Товары → поиск по артикулу → карточка → фото → Alt.
  2. Не писать alt в поле «Текст» карточки.

2 Волна 2. Общие блоки - логотипы клиентов и отзывы

Что сделать

Один раз проставить Alt у файлов, которые повторяются на многих страницах (лента клиентов, сканы писем, превью видеоотзывов). Править на любой странице, где блок виден - чаще на «Клиенты», «О компании» или «Внедрение 1С».

Зачем

Иначе одна и та же картинка без подписи тиражируется на десятки URL.

Как в Тильде
  1. Откройте страницу Клиенты или О компании → карандаш.
  2. Найдите блок с логотипами / письмами / видеоотзывами.
  3. Контент → многоточие у картинки → Alt.
  4. Если блок общий (алиас) - правка один раз обновит все страницы.
  5. Мелкие SVG-иконки в этом блоке не трогать.
Иконку виджета мессенджера (файл без расширения 29557530) не заполнять.

4 Волна 4. Остальные страницы сайта

Что сделать

Пройти остальные URL из меню и карты сайта тем же приёмом. Готовые тексты ниже - шаблоны под тип картинки.

Зачем

Чтобы не оставлять пустые фото на второстепенных лендингах (боты, отраслевые, старые кейсы).

Как в Тильде
  1. Откройте страницу → карандаш.
  2. Смысловое фото (обложка, скрин, портрет, сертификат, коллаж) - заполнить по таблице.
  3. SVG, Tilda Icons, эмодзи, мелкие иконки преимуществ - пропустить.
  4. Логотип в шапке - не трогать (уже «Аллсан» на весь сайт).
Тип картинкиЧто писать в Alt
Обложка / первый экранКоротко по H1 страницы (без цены и города)
Пункт аккордеона с фотоЗаголовок этого пункта
Скрин интерфейса / модуля«Скрин: …» + что на экране (остатки, заказы, склад)
Портрет сотрудникаФИО и должность, если видны рядом; иначе «Специалист Аллсан»
Сертификат / диплом«Сертификат Аллсан Интеграция» или точное имя с подписи
Коллаж клиентов«Клиенты Аллсан»
Логотип известного клиента«Логотип …» + имя компании
Скан письма / отзыв«Благодарственное письмо клиенту Аллсан» или «Отзыв клиента Аллсан»
Превью видеоотзыва«Видеоотзыв клиента Аллсан»
Страницы ботов (/telegram1c, /whatsapp, /tb*) - бота с продажи не возвращаем, но Alt у смысловых фото можно поставить по таблице. Декор и SVG не трогать.

Что сделать

После каждой страницы или пачки карточек - «Опубликовать» (отдельное письменное «да»).

Зачем

Иначе подписи останутся только в черновике Тильды.
