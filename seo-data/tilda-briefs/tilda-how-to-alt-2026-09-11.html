Как в Тильде поставить Alt у картинки

Дата: 11.09.2026. По официальной справке Тильды. Для страницы модуля: /casemarketplace (задача T2-4).

Простыми словами. Alt — короткая подпись к картинке. Её не видно на красивой странице, но она нужна, если картинка не загрузилась, и её читают программы для незрячих и поисковики. В Тильде Alt не пишут в HTML-коде страницы вручную — его задают в настройках картинки в блоке.

0 Что такое Alt

Что сделать

Понять, куда в Тильде вписывается подпись к картинке.

Зачем

Чтобы не искать поле «в коде сайта» — его там править не нужно.

Как устроено
  1. Открываете страницу в редакторе Тильды.
  2. Открываете Контент нужного блока (не «Настройки сайта»).
  3. Находите нужную картинку в списке загрузок блока.
  4. В зависимости от типа блока — многоточие, ссылка «Текст» или поле ALT в Zero Block (ниже три способа).
  5. В конце: Сохранить страницу → Опубликовать.

A Обычные блоки — «Контент» → многоточие

Что сделать

Прописать Alt для картинки в обычном блоке с фото/иллюстрацией (не галерея и не Zero).

Зачем

Так устроены большинство блоков на лендинге модуля.

Как в Тильде
  1. Список страниц → нужная страница → карандаш (редактор).
  2. Наведите на блок с картинкой → кнопка «Контент» (иногда иконка текста / Content).
  3. В окне контента найдите загруженное изображение (превью / имя файла).
  4. Напротив картинки нажмите знак многоточия «…».
  5. В появившемся поле «SEO: alt-текст для изображения» вставьте текст.
  6. Закройте окно / подтвердите → вверху редактора Сохранить → Опубликовать.
Редактор → блок → Контент → … напротив картинки → «SEO: alt-текст для изображения» → Сохранить → Опубликовать

Источник: Гид по SEO Тильды · Цифровая доступность

B Блоки «Галереи» — ссылка «Текст»

Что сделать

Прописать Alt для фото в блоке из категории «Галереи».

Зачем

В галереях другое меню: многоточия может не быть, вместо него — «Текст».

Как в Тильде
  1. Редактор → блок галереи → «Контент».
  2. Напротив нужной картинки нажмите ссылку «Текст».
  3. В поле Image alt for SEO (alt-текст для SEO) впишите описание.
  4. При необходимости заполните заголовок/описание слайда — это не то же самое, что Alt (заголовок может показываться на экране).
  5. Сохранить → Опубликовать.
Контент галереи → Текст → Image alt for SEO → Сохранить → Опубликовать

Источник: Гид по SEO · Галереи

C Zero Block — поле ALT у элемента

Что сделать

Прописать Alt у картинки внутри Zero Block.

Зачем

В Zero картинки — отдельные элементы; путь через «Контент → …» часто не подходит.

Как в Тильде
  1. Редактор → блок Zero → войти в редактирование Zero (двойной клик / «Редактировать Zero»).
  2. Кликните по нужному изображению на холсте.
  3. Справа в панели настроек элемента найдите поле ALT / альтернативный текст.
  4. Вставьте текст → сохраните Zero → сохраните страницу → Опубликовать.
Zero Block → клик по картинке → панель справа → ALT → Сохранить → Опубликовать

Источник: Блог Тильды про alt · Zero Block

! Как писать текст в Alt

Что сделать

Писать коротко и по сути картинки.

Зачем

Длинный набор ключей поисковики могут воспринять как спам; пустой смысл бесполезен людям.

Правила (по Тильде)
  1. Опишите, что на картинке, своими словами — как будто рассказываете по телефону.
  2. Рекомендуемая длина — до ~125 символов.
  3. Не начинайте со слов «картинка», «изображение», «фото».
  4. Не набивайте ключи подряд.
  5. Текст должен совпадать с темой страницы (для модуля — 1С, Ozon, Wildberries, функции модуля).
ПлохоНормально
картинкаМодуль интеграции 1С с Ozon и Wildberries
1с озон вайлдберриз модуль купить ценаЮнит-экономика и маржа Ozon и Wildberries в 1С
